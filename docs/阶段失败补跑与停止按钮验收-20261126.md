## 实施内容

- 增加 `CO_DISCOVERY_PASS_COUNT` / `CO_MERGE_PASS_COUNT`，默认 1，正整数且包含首次。步骤 YAML 对应 `discovery_pass_count` / `merge_pass_count`，CLI 支持同名连字符参数。
- 局部阶段先完成独立批次，再只补跑失败批次；成功检查点和拆分后的成功子任务可复用。合并在当前层补齐失败后才进入下一层；补跑历史采用独立 pass 路径，缓存身份不随轮数变化。
- 普通暂时服务错误及响应校验失败可补跑；unknown 不自动重发，合并遇到 unknown 停止提交后续批次。鉴权/配置拒绝和无法再拆分的预算错误不盲目重试。轮数耗尽保留 partial。
- 每个步骤执行按钮后增加停止按钮，绑定本行活跃任务 ID；排队可取消，运行中复用本地进程树取消接口。停止中禁用按钮，未确认退出前保留锁。停止本地进程不表示远端服务计算停止。
- 局部记录 `schema/local-passes.json`，合并记录 `schema/merge-passes/round-*.json`；网页和事件保留轮数、累计成功及剩余数量。
